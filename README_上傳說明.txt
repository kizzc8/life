GitHub Pages 上傳版

請把以下 7 個檔案全部放在 life repository 的最外層：
- index.html
- styles.css
- app.js
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png

不要建立子資料夾。

GitHub Pages 維持：
Settings → Pages
Source: Deploy from a branch
Branch: main
Folder: /(root)

更新完通常等 1–3 分鐘，再用 Safari 開：
https://kizzc8.github.io/life/

iPhone 安裝：
Safari → 分享 → 加入主畫面

如果更新後仍看到舊版：
1. Safari 重新整理
2. 等 30–60 秒再開
3. 若已加到主畫面，關閉 App 後重開
4. 必要時刪除主畫面舊圖示，再從 Safari 重新加入一次

注意：
資料存在瀏覽器 localStorage。重設網站資料或換手機前，先按「匯出 JSON」備份。
